# C-fundamentals-
C# Fundamentals 2024
Project Milestone 2
Introduction
Rewind’s owner, Mr. Marty McFly approved your planned application for the loyalty program and
requested that the loyalty program should be integrated into the cash register system.
Practical
Write a C# console application that will simulate Rewind’s Loyalty Program. The application needs to
make use of an initial customer entry form to obtain the customer details, followed by multiple Enumdriven menus to calculate the discounts, coupons and rewards the customer is eligible for. Finally, the
customer should be able to order from a list of VHS tapes, DVDs, and CDs. At checkout, the discounts,
coupons, and rewards should be applied, and the total amount displayed to the user.
Please follow the instructions below:
• The application should be a C# console application.
• The application should make use of Enum menus.
• Make use of methods to generate new menus and enforce reusable code.
• The application should allow you to order various media.
• It should keep track of what you have ordered as well as how much it costs.
• A person should be able to check out their order and if they do it should display theitems
ordered as well, the total price due as well as any additional couponsor rewards.
• The application should loop and after checkout, it should reset your cart. Itshould also give
you the option to close the application.
Important notes:
• Refer to your pseudocode, flowcharts, and research materials throughout the
implementation process.
• This project should be completed in groups of 3 students
• Every individual should submit the project.
• Make use of comments in your C# code to list the names of group members and to keep track
and explain the functionality of code blocks, this will be useful to both your team as well as
lecturers to understand and follow the logic used.
Project defense:
• On 6 and 7 August 2024 you will be randomly assigned a timeslot to explain your project.
• You will have 5 minutes to walk the lecturer through your project.
• The lecturer will question you for 25 minutes to test your understanding of your own code.
• Each member of the group will be questioned and is required to be present.
